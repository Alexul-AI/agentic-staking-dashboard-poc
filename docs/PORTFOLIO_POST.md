## 7. 2-Minute Technical Walkthrough

This project is an Agentic Staking Dashboard PoC.

The smart contract is deployed on Ethereum Sepolia. It supports staking ETH, withdrawing, claiming rewards, funding the reward pool, updating reward rate, and emitting events for key actions.

The frontend is built with React, TypeScript, wagmi, viem, and Tailwind CSS. It connects to MetaMask, checks the Sepolia network, displays staking state, shows transaction lifecycle status, and links to Etherscan.

The dashboard also shows reward pool liquidity, because in staking systems user rewards and contract liquidity are separate concepts.

On top of that, I added a backend DeFi mock context API. It simulates APY, gas condition, pool health, risk level, and liquidity status.

The AI Auto-Pilot layer uses the on-chain state plus backend context to generate a structured recommendation:

```text
Action
Confidence
Reasoning
Context Used
Recommended Next Step
Execution
Risk Note
```

The AI does not control the wallet. It cannot sign transactions or move funds. Every blockchain write action still requires the user to click manually and confirm through MetaMask.

For security and production-readiness, I added OpenZeppelin `ReentrancyGuard`, OpenZeppelin `Ownable`, smart contract events, Hardhat tests, AI proxy validation, rate limiting, AI evaluation guardrails, event-monitoring automation architecture, and B2B proposal documentation.

The purpose is to demonstrate how an AI Operator can move a Web3 product from smart contract logic to a usable, explainable, and safer dashboard experience.
